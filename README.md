# 🌳 树洞 · 只属于你的小树洞

一个安静甜美的情绪树洞：像好朋友一样陪你聊天，帮你把情绪和背后的原因一层层理清楚。每天 19:00 自动生成「情绪小记」。

## 特点

- 💬 **好友式聊天**：不说教、不打官腔，分条分点、一针见血地帮你分析情绪
- 🌙 **每日情绪小记**：每天 19:00（可调）自动分析当天的情绪和产生原因
- 📚 **多话题**：每个话题独立保存，隔多久都能接着聊
- 🔒 **纯本地数据**：聊天记录只存在你自己的浏览器里，网站服务器不保存、不上传任何信息
- 🔑 **各用各的 Key**：每个人的 API Key 只存在自己的浏览器里，互不共享

## 怎么用（公开网页版）

1. 打开网址，点右上角 ⚙️
2. 去 [platform.deepseek.com](https://platform.deepseek.com) 免费注册领一个 API Key
3. 填进设置（自动保存，下次打开不用再填）
4. 开始聊天 ❤️

## 本地版

下载本项目，双击 `start.bat`，树洞就在你电脑上跑起来（只允许本机访问）。

## 隐私说明

- 无后端、无账号、无数据库：所有数据都在你浏览器的 localStorage 里
- 聊天内容只会在你发消息时发给你自己填的 AI 接口，用于生成回复
- 本仓库只包含静态网页文件，不含任何人的 API Key 或聊天数据
